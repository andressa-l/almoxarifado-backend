## Projeto Almoxarifado
<p> A concepção inicial do projeto, em termos de arquitetura, utilizou o DDD, a linguagem de programação C#, Banco de dados SQL, ASP.NET Core, Entity Framework e Automapping. O objetivo é implementar a visão de negócio de Estoque de produtos com uso de metodologias de código e arquitetura avançada tais como: clean code, Design Pattern, SOLID, TDD.</p>
